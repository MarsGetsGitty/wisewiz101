# WiseWiz101 Web — Gear Database Browser

A Next.js gear database browser for Wizard101, featuring 50,000+ items extracted from game data.

## Quick Start

```bash
cd web
pnpm install
pnpm dev
# Open http://localhost:3000
```

## Architecture

```
web/src/
├── app/                    # Next.js App Router pages
│   ├── layout.tsx          # Root layout (fonts, header, theme)
│   ├── page.tsx            # Main browser (search + filter + table)
│   └── items/[name]/       # Item detail page (dynamic route)
├── components/             # React components
│   ├── FilterSidebar.tsx   # Multi-select school/type/rarity/level filters
│   ├── GearTable.tsx       # Virtualized table (50k rows, dynamic stat cols)
│   ├── ItemCard.tsx        # Full item detail card
│   ├── SearchBar.tsx       # Debounced text search with result count
│   └── StatBadge.tsx       # Color-coded stat display (flat=blue, %=pink)
├── data/                   # Data access layer
│   ├── types.ts            # TypeScript interfaces (GearItem, GearFilters)
│   └── repository.ts       # Static JSON fetch with cache (v2: swap to SQLite)
├── hooks/                  # React hooks
│   ├── useGearData.ts      # Fetch + cache all items, extract filter options
│   └── useFilters.ts       # Filter/sort state, debounced search, memoized pipeline
└── lib/                    # Pure utilities
    ├── constants.ts        # School colors, rarity labels, stat formatting
    └── filters.ts          # searchItems(), filterItems(), sortItems()
```

## Data Source

The gear data comes from `public/data/gear_database.json`, generated by the Python extractor pipeline. To refresh:

```bash
# From project root
python src/gear_extractor.py --output output/gear_database.json
cp output/gear_database.json web/public/data/
```

## Design System

- **Theme**: Dark fantasy (deep purples, gold accents, starfield background)
- **Fonts**: Cinzel (headings), Outfit (body)
- **School colors**: Each Wizard101 school has its own color + emoji
- **Stat colors**: Flat stats = blue, Percentage stats = pink
- **Rarity colors**: Common (gray) → Uncommon (green) → Rare (blue) → Epic (purple)

## Key Decisions

1. **Virtual scrolling** — Custom implementation with spacer rows for 50k items
2. **Data layer abstraction** — `repository.ts` can be swapped from static JSON to SQLite/API without changing any UI components
3. **Debounced search** — 300ms delay prevents re-filtering on every keystroke
4. **Dynamic stat columns** — The top 6 most common stats are auto-detected as table columns
